# Hook library — opening shapes from outliers

A shape = the structure of a proven opening with the topic removed. Copy the shape, fill the subject (rules/02-hooks.md).
Refreshed 2026-10-17 from real outliers in the Claude / Opus 5.5 video-editing niche (NexLev). Shapes are abstracted,
not quoted: write your own words into them.

## Rules for adding a shape
- Only from a video with ≥ 3x its channel's normal views (NexLev outlier score), opening ≤ 3 sentences.
- Write the shape with brackets, add one Example in your own words, link the source, note the multiple.
- Keep ≤ 15 rows. After using a shape, note the video and its CTR / 30s retention so the library learns too.
