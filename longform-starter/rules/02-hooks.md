# 02 · Hooks

The first line comes from the hook library (`references/hook-library.md`), never from a blank page.

1. The library holds **shapes** taken from outliers: videos that got 3x+ their channel's normal views. A shape is the
   structure with the topic removed.
2. **Copy the shape word for word, then fill it** with this video's subject. Be creative about the subject, not the structure.
3. The hook must be provable **on screen in frame one**. An "AI edited this video" hook works because the viewer is
   looking at the edit while hearing it.
3b. **When the hook names things on screen, SHOW each one as it's named**: "the headlines, the
   cards, the cuts, the circle I'm in" = a headline appears and gets tagged, a card slides in, a timeline gets cut, an
   arrow lands on the bubble — each on its word. Text chips that just repeat the words don't count. Build it as a
   custom fragment.
4. Hook = ≤ 3 sentences, ≤ 15–20s. Line 1 claims, line 2 points at the proof, line 3 names what feels impossible about it.
5. Refresh the library every 30 days: NexLev `youtube_channel_outliers` on the channels in your competitors list → for the
   top outliers, `get_video_transcript` → take the first 2–3 sentences → abstract them to a shape → add a row with the source
   link and the outlier multiple. Keep the 15 best shapes; retire what stops working.
