# Fact check

Every number, date, name-drop claim, or "X did Y" statement in the script gets a row. **No source = cut the line.**
A source is something you can open: a file path in this HQ, a URL, a screenshot in assets/img/. "I remember" is not a source.

`script_lint.py` fails any script sentence containing a number that isn't covered by a row here
(it matches on the number itself, so write the number in the claim exactly as it's spoken).
