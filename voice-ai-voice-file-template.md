# The AI Voice File (fill-in-the-blanks template)

*From my "Why your AI sounds like a robot" short. — Dara*

Your AI sounds generic because it has never been told who you are. Fill this in once, then paste it at the top of every chat, or save it as a custom instruction / project instruction so it loads automatically.

Takes about 15 minutes. Copy everything inside the box.

```
# WHO I AM
I'm [name], a [what you do] for [who you serve].
I write [posts / emails / scripts / newsletters] for [platform or audience].

# MY 5 RULES
1. [How long: e.g. "Short sentences. Most under 15 words."]
2. [Tone: e.g. "Friendly and direct, like texting a smart friend."]
3. [Structure: e.g. "Lead with the point, then the proof."]
4. [Formatting: e.g. "No bullet lists unless I ask. No emojis in emails."]
5. [Your quirk: e.g. "I use one concrete number in every post."]

# 3 WORDS (OR PHRASES) I'D NEVER SAY
- [e.g. "delve"]
- [e.g. "game-changer"]
- [e.g. "In today's fast-paced world"]

# 2 PARAGRAPHS IN MY REAL VOICE
Match the rhythm, word choice and energy of these. Don't copy the content.

[Paste paragraph 1: something you actually wrote that sounds like you. A post, an email, a caption.]

[Paste paragraph 2: a different context. If paragraph 1 is a post, make this an email or a DM.]

# BEFORE YOU ANSWER
Write like the samples above. If a sentence sounds like default AI, rewrite it.
```

## Where to put it

- **ChatGPT:** Settings → Personalization → Custom instructions (or a Project's instructions).
- **Claude:** a Project → Project instructions, or Settings → Profile preferences.
- **Anywhere else:** paste it as the first message of the chat.

## Make it better over time

Every time the AI writes something that isn't you, ask "which rule would have stopped this?" and add it. After a month, your file will catch most of it.
